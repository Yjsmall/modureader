## Interface preview

Warm paper backgrounds, coral action buttons and rounded cards now extend across the bookshelf, notes, reading history, remote library, sentence contexts, AI, search and settings. Dark mode pairs charcoal backgrounds and layered gray surfaces with light text and coral buttons. Custom theme colors, OLED black and E-ink modes remain available.

![Desktop bookshelf with sidebar navigation, a continue-reading card, search and reading-status filters](docs/design/previews/bookshelf-desktop.png)

| Mobile light mode | Mobile dark mode |
| --- | --- |
| ![Light bookshelf with rounded bottom navigation](docs/design/previews/bookshelf-phone-light.png) | ![Dark bookshelf with rounded bottom navigation](docs/design/previews/bookshelf-phone-dark.png) |

Mobile uses rounded bottom navigation, with secondary pages under **More**; desktop uses a sidebar that collapses in narrower windows. The bookshelf offers continue reading, search, reading-status filters and grid/list views. Settings are grouped into reading, intelligent assistance, data and support.
