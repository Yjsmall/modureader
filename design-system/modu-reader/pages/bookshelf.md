# 书架页 · 浅彩色卡片

本页覆盖 MASTER.md 的中性表面与书架布局规则。当前仅在书架页试用；其他页面的配色不随之变更。

视觉参考是本地 8765 端口的 `docs/design/bookshelf-pastel-preview/` 原型。采用珊瑚色重点操作、白色外卡、局部浅色封面展示区；根据用户反馈去掉浅紫色。

## 表面与重点色

| 角色 | 浅色 | 使用方式 |
| --- | --- | --- |
| 页面 | `#FBF9F5` | 奶白底色 |
| 书籍外卡 | `#FFFDFA` | 白色表面与细边框 |
| 继续阅读 | `#FAE6DC` | 蜜桃色主卡 |
| 未开始 | `#F8E8DF` | 封面展示区的浅桃色 |
| 正在读 | `#E7EEE5` | 封面展示区的鼠尾草绿 |
| 已读完 | `#F1ECDA` | 封面展示区的浅麦色 |
| 主要操作 | `#C94C35` | 导入、继续阅读及在读进度 |
| 完成进度 | `#50765D` | 已读完状态与进度 |
| 正文 / 次级文字 | `#302D32` / `#716960` | 在浅色表面保持可读 |

阅读状态沿用现有 2% / 98% 阈值；进度数字提供文字信息。文件夹按照稳定的分组 ID 选择配色，排序不改变颜色。

## 布局与交互

- 主卡圆角 26dp，留白 20–28dp；普通外卡圆角 24dp，封面展示区圆角 16dp，外层留白 10dp。细边框配合柔和外阴影，墨水屏关闭阴影。
- 继续阅读从当前未完成书籍中选择最近更新的一本，与现有“上次阅读”排序的时间字段一致；没有合适的书则隐藏。筛选、选择及列表模式下隐藏主卡。
- 主卡、收藏标题、搜索、状态导航及网格共用一个原生 CustomScrollView；搜索移到收藏标题区域，宽屏同排、手机纵排。主卡宽度上限 720dp，网格按可用宽度和封面设置调整列数。
- 主卡文字在左，轻微倾斜的封面在右，以原生 Canvas 绘制细圆环衬底。墨水屏不旋转封面。
- 保留封面 2:3 比例，在浅色展示区中居中；普通卡书名预留两行，作者、状态、进度基线一致。主卡有独立 Hero 标签，避免与网格封面冲突。
- 保留原字体家族和用户阅读字体；普通卡书名 14dp，作者 11dp，状态 / 进度 10dp，主卡引用现有语义文字样式。
- 状态导航使用内容宽度的浅米色分段底块与白色选中表面；同时通过状态文字和百分比表达阅读状态。
- 字号增大时主卡改为纵排、网格改为单列，内容随页面滚动。
- 保留搜索、导入、排序、标签、同步、拖放、文件夹、批量选择及书籍操作。列表模式仍隐藏封面。
- 通过书架内部 ThemeExtension 实现页内样式，共用组件在其他页面沿用原有外观。
- 原型中的引言、章名、今日时长为演示数据，不写入真实应用；继续阅读与状态信息来自当前书籍数据。

## 实际渲染

预览位于 `docs/design/previews/`，由真实 Flutter 组件及虚构书籍数据生成。检查手机深浅色、桌面、横屏、2× / 3.2× 字号，以及列表与批量操作。完整 Linux 启动受本机缺少 Ninja / C++ 编译器影响。
