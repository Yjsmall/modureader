# 默读 · 已确认的全局界面规范

书架样式已由用户确认，以 8765 端口原型为视觉参考；现应用到导航、笔记、历史、远程书库、句境、AI、搜索、设置与相关弹窗。全局主题由 `lib/theme/app_theme.dart` 提供，书架特有的封面展示区规则见 `pages/bookshelf.md`。

## 字体与用户配置

- `AppTheme.apply` 保持原 TextTheme 和 AppBar 标题字体，保留既有系统字体与思源宋体，不引入远程字体。
- 阅读正文的用户字体、字号、背景及 CSS 配置不变；阅读工具标题仍为原思源宋体、28 号粗体。
- 笔记与历史的原字体家族、字号、字重保留。数字强调文案从现有 Theme 继承正确文字样式，并支持系统字号缩放。
- 自定义主题色继续生效；旧内置中性色映射到已确认的珊瑚色默认方案。保留深色、OLED 纯黑及墨水屏设置。

## 颜色与容器

| 角色 | 浅色默认值 |
| --- | --- |
| 页面背景 | `#FBF9F5` 奶白 |
| 内容卡片 | `#FFFDFA` 白色 |
| 主操作 | `#C94C35` 珊瑚色 |
| 选中背景 | `#FBE9E2` 浅桃色 |
| 次级概览 | `#E7EEE5` 鼠尾草绿 |
| 计数概览 | `#F1ECDA` 浅麦色 |
| 边界 | `#ECE7E0` |
| 正文 / 次级文字 | `#302D32` / `#716960` |

- 普通卡片圆角 24dp，主卡 26dp，控件 14dp，弹窗 26dp，底部弹层顶部 28dp。
- 普通内容保持白色，浅彩色用于概览、选中状态、词语标签或封面衬底；不用整页浅紫色填充。
- 卡片用细边框和低强度阴影区分层次。墨水屏采用黑白灰和明确边框，关闭阴影。

## 深色适配

| 角色 | 深色默认值 |
| --- | --- |
| 页面背景 | `#141619` 中性炭灰；OLED 模式为纯黑 |
| 普通卡片 | `#202327` |
| 输入框 / 较低表面 | `#191B1F` |
| 底栏、菜单与弹窗 | `#2A2E33` |
| 主按钮 / 按钮文字 | `#C94C35` / `#FFFFFF` |
| 链接、选中标识与进度 | `#EA8F7B` |
| 浅桃色概览对应表面 | `#332827` |
| 鼠尾草绿概览对应表面 | `#24322D` |
| 麦色概览对应表面 | `#302F29` |
| 正文 / 次级文字 | `#ECEEF0` / `#AAB0B8` |
| 边界 | `#383E46` |

- 使用中性炭灰的明暗层级，彩色衬底只作低饱和度点缀。
- 深色阴影使用黑色，避免浅色阴影形成白色光晕。
- 主操作的实心按钮使用珊瑚红白字，文字链接及选中标记使用较亮的珊瑚色；禁用按钮仍使用原生禁用样式。
- 底栏与弹窗高于普通卡片一层；输入框在卡片内部使用较深表面。
- 正文、次级文字、按钮和各类浅彩衬底的文字检查 4.5:1 对比度。浅色模式与原字体保持现有设置。
- 页面外边距通常 24dp；主内容卡片留白 20–24dp。紧凑统计格、菜单和控件按可用空间调整。
- 封面保持原比例；文本区域预留标题、作者与进度基线。进度使用圆角轨道，移除多余终点圆点。

## 页面组织

- 书架保留已确认的继续阅读主卡、收藏区域搜索、分段阅读状态导航、白色外卡与浅色封面展示区。
- 导航使用珊瑚色选中标识；桌面侧栏用浅桃色选中背景。手机底栏采用 24dp 圆角、左右各 12dp 留白，与安全区间隔 12dp，使用细边框与轻阴影；最多五个入口，更多弹层保留全部次要页面。墨水屏关闭阴影。
- 笔记使用浅桃色计数概览与白色书籍卡片，封面置于局部鼠尾草绿衬底；桌面列表与详情以留白分隔。详情中的书籍信息与笔记相距 24dp。
- 历史中的统计卡片以浅彩色区分用途，记录列表保持白卡，统一内边距、圆角与进度样式；卡片编辑、拖拽、翻面和记录删除保留。
- 设置在手机端使用按主题分组的白卡；桌面使用白色分类目录与独立详情区域。选中分类以浅桃色标识。
- 远程书库的文件与文件夹使用独立白卡与浅色图标衬底，筛选、排序、导航和下载操作保留。
- 句境使用白色文档 / 句子卡片及浅色词语标签；复制、删除与返回刷新保留。
- AI 对话使用浅桃色用户消息、白色回复、细边框与统一圆角；输入区、技能菜单及空状态沿用共享容器。
- 搜索、笔记详情、各设置子页及相关菜单 / 弹窗继承同一主题。
